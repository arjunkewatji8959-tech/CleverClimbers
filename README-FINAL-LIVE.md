# CleverClimbers — Final Live Website

Company website package prepared for desktop, tablet and Android/iPhone browsers.

## Local run

1. Open this `CleverClimbers` folder in VS Code.
2. Open Terminal.
3. Run:

```powershell
npm install
npm start
```

4. Open `http://localhost:5000`

## Live hosting

This is a Node.js + Express website. Use a Node.js web-service host such as Render. The start command is:

```text
npm start
```

The server already uses the hosting-provided `PORT` environment variable.
